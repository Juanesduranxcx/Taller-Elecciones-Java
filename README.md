# 🗳️ Sistema de Conteo de Votos (Taller 4)

Este es un programa desarrollado en **Java** que procesa resultados electorales a partir de un archivo de texto, utilizando diferentes sistemas de votación como el **Método de Borda**.

## 🚀 Funcionalidades
- **Lectura Segura:** Procesa datos desde un archivo `.txt` con manejo de excepciones (`try-catch`) para evitar cierres inesperados.
- **Lógica Electoral:** Calcula votos válidos, nulos y puntos acumulados por cada candidato.
- **Resultados Precisos:** Identifica ganadores y muestra el estado final de la elección por consola.

## 🛠️ Tecnologías Usadas
- Java (JDK 17+)
- Programación Orientada a Objetos (POO)
- Git/GitHub para control de versiones

## 📊 Estado del Proyecto
El programa se encuentra **100% funcional**. Durante el desarrollo se corrigieron detalles técnicos en la estructura de los objetos y constructores, logrando una solución estable que cumple con todos los requisitos de la guía académica.

## 📝 Ejemplo de Uso
El sistema espera un archivo llamado `votos.txt` con el formato de preferencias por candidato. Al ejecutar, el programa genera un resumen detallado con el método aplicado, totales y el ID del ganador.
